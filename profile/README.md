<h1 align="center">ChoreStrike</h1>

<p align="center"><b>Shared chores, fair plans, less reminding.</b></p>

ChoreStrike is a household task app for **Nextcloud**. Families and flatmates
organize their home in floors and rooms, plan a fair week together, and work
through a calm *My Day* list — all inside their own Nextcloud, with no
external service.

<p align="center">
  <img src="https://raw.githubusercontent.com/ChoreStrike/ChoreStrike/master/docs/screenshots/my-day.png" width="720" alt="My Day: today's agreed tasks, each with a Done button and an optional checklist">
</p>

**Status:** alpha (`0.8.0-alpha.1`); not yet in the Nextcloud App Store. A privately maintained, non-commercial open source
